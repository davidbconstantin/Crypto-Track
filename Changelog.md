# Current project scope

CryptoTrack's main landing page is a working cryptocurrency market dashboard including the top 100 market coins, though no separate page coins are coded yet.

## Included
- React + TypeScript frontend built 
- CoinGecko API request for the top 100 coins
- Market summary cards and a cryptocurrency table
- Search by coin name or ticker symbol
- Loading, refresh and error states
- Responsive styling 
- Aesthetic website frontend
